Salvar no meu painel

O QR Code apontará para um link curto que conta cada abertura e redireciona para o seu destino.

Como usar

  1. Escolha o tipo de conteúdo: link, texto, Wi-Fi, WhatsApp, Pix e outros.
  2. Preencha os campos. O QR Code é atualizado em tempo real.
  3. Personalize cores, formato dos pontos, olhos e logo.
  4. Baixe em PNG (alta resolução) ou SVG (vetorial, ideal para impressão).

Saiba quem abriu cada QR Code

Precisa só de um QR Code rápido? Use o gerador acima, sem cadastro. Mas se o QR Code vai para um cartaz, cardápio, embalagem ou campanha, crie sua conta grátis e acompanhe os resultados.

Contagem de aberturas

Quem clicou e como

Celular ou computador, Android ou iPhone, navegador, idioma e horário de cada abertura, com exportação para planilha.

Links dinâmicos

Mudou o site ou a promoção? Troque o destino no painel e o QR Code já impresso passa a abrir o novo link.

Pausar quando quiser

Campanha encerrada? Pause o link com um clique e reative depois, sem precisar de outro QR Code.

Sobre

O QR Code Fácil é um projeto open-source. Sem conta, todo o processamento acontece no seu navegador: nenhum dado digitado é enviado ao servidor, e os QR Codes gerados são estáticos, não expiram e não possuem rastreamento. Com conta, só os QR Codes que você decide salvar ficam guardados no seu painel, e os links rastreados registram aberturas de forma anônima.
